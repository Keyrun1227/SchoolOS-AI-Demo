# SchoolOS AI UI Demo — Role & Workflow Redesign

Open `schoolos-ui-demo/index.html` in a modern browser. No AI keys, database, server, or installation required.

## Included
- Principal: school-wide overview, time-period comparisons, class top/lowest performers, teacher progress/context, assessment status, personal notes and school to-do list.
- Teacher: daily timetable and planning notes, assigned Science classes (8A, 9A, 10B), Science-only assessment creation and assessment list, marks workflow, class progress, doubt inbox, revision and retest follow-up.
- Student: personal progress, topic gaps, class position movement, separate teacher-assigned and self-assigned revision, ask-teacher flow.
- Parent: linked-child view with a fictional multi-child switcher, child-specific subject results, attendance and school updates.
- Browser-local notes/tasks for prototype feedback.

All records are fictional. Role switching is a preview, not secure authentication or authorization. No backend, AI, upload or live school data is connected.
